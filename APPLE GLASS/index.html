Fundamentos

material, cor, tipo, ícones, cantos

Material Liquid Glass

Regular desfoca e ajusta o brilho do fundo para o texto ficar legível (barras, menus, alertas). Clear é mais transparente, só sobre mídia rica. Em fundo claro, coloque a camada .lg-dim (35%) por baixo. Tint só na ação principal. Passe o mouse para ver o brilho.

Menus e ações

botões, toolbar, menus

Botões

Seis estilos. Use Filled ou Glass prominent para a ação principal (uma por tela). Glass para botões que flutuam sobre conteúdo. Tamanhos --sm, padrão (44px, área mínima de toque) e --lg.

HIG › Menus and actions › Buttons

Toolbar (grupo de botões)

Ações relacionadas dentro de uma cápsula de vidro, com separador. Ideal flutuando no rodapé de uma galeria, mapa ou player.

HIG › Menus and actions › Toolbars

Menu suspenso e menu de contexto

Botão com data-lg-menu dentro de .lg-menu-wrap abre o menu com efeito de mola. Ações destrutivas em vermelho e no fim. Clique com o botão direito no cartão para o menu de contexto.

Como usar nos sites

  1. Copie glass.css e glass.js para a pasta do site.
  2. No <head>: <link rel="stylesheet" href="glass.css">. No fim do <body>: <script src="glass.js"></script>.
  3. Se usar ícones, cole o bloco <svg> de símbolos (topo deste index) logo depois do <body>.
  4. Para a cor do cliente: :root{ --lg-accent:#e30613 }. Tema fixo: <html data-theme="dark">.
  5. Em cada bloco aqui, clique em Código para ver e Copiar para levar o HTML.
  6. Conteúdo criado depois que a página carregou: chame LG.init(elemento).
<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1,viewport-fit=cover">
  <link rel="stylesheet" href="glass.css">
  <style> :root{ --lg-accent:#007aff } body{ margin:0; font:var(--lg-t-body); background:var(--lg-bg); color:var(--lg-label) } </style>
</head>
<body>
  <!-- sprite de ícones aqui -->
  <nav class="lg-navbar lg-navbar--sticky lg-glass">…</nav>
  <main>…</main>
  <script src="glass.js"></script>
</body>
</html>
